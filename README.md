# GameSlop Arcade Playtest

Public browser playtest for GameSlop: five new original arcade games, Scrap Assault, a Retro Cabinet, and the earlier ten short-form cartridges.

The new originals are Jungle Protocol, Iron Convoy, Neon Uprising, Slop Showdown and Starfall Squadron. They include complete first stages or an arcade ladder, keyboard/touch controls and local unranked scores. These are playtests, not full commercial-length campaigns.

This repository contains compiled static assets only. The private application source, Telegram bot, score backend, and deployment configuration are maintained separately.

Demo scores and the sample player identity remain in the visitor's browser and are not uploaded.

The Retro Cabinet loads EmulatorJS from its CDN and includes a redistributable NES homebrew. Commercial ROMs/BIOS files are not bundled. User-selected ROM files stay local to the browser; compatibility varies by title/core.
